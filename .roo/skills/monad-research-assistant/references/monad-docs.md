## Monad Teknik Detayları
- **Async Execution**: Consensus ve execution katmanlarını ayırarak 0.3s block time.
- **Parallel Execution**: Bağımsız işlemler paralel yürütülür (10,000+ TPS).
- **MonadBFT**: PoS tabanlı consensus mekanizması.
