# Monad Blitz Hackathon Kuralları

## Zorunlu Kurallar
1. **Tüm proje kodu bugün yazılmalı** (mevcut projeler kabul edilmez).
2. **Her proje canlı olarak deploy edilmeli** (localhost kabul edilmez).
3. **Kod herkese açık GitHub repository'sinde olmalı**.
4. **Demo 3 dakika içinde tamamlanmalı**.

## Değerlendirme Kriterleri
- **Yenilikçilik**: Yeni fikirler ve mekanikler.
- **Teknik Derinlik**: Monad'ın özelliklerini kullanma.
- **Demo Kalitesi**: Çalışan bir ürün sunumu.

## Öneriler
- **UI/UX**: Tasarım kiti kullanın (örn: Tailwind, Polaris).
- **Demo Akışı**: Formları önceden doldurun.
- **Slides**: Minimum slayt, maksimum demo.
